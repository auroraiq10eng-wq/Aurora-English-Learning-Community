# Aurora — أورورا

الموقع الرسمي لمجتمع أورورا لتعلّم اللغة الإنكليزية.
**Learn. Connect. Grow.**

🔗 الموقع: https://auroraiq10eng-wq.github.io/Aurora-English-Learning-Community/

## أين أعدّل؟

كل محتوى الموقع موجود في ملف واحد: **`assets/js/content.js`**

| ماذا تريد أن تغيّر؟ | القسم داخل الملف |
|---|---|
| الجلسة القادمة ورابط التسجيل | `nextSession` |
| الجلسات السابقة | `previousSessions` |
| أعضاء الفريق | `team` |
| صور "لحظاتنا" | `gallery` |
| روابط التواصل | `links` |
| نموذج الملاحظات | `feedback` |
| أسئلة وأجوبة Ask Aurora | `faq` |

- حالة التسجيل `status`: `open` مفتوح، `soon` قريباً، `full` اكتمل العدد، `closed` مغلق.
- الصور توضع داخل `assets/img/` ثم يُكتب مسارها في الملف.

## الملفات

```
index.html            هيكل الصفحة
assets/css/style.css  التصميم والألوان
assets/js/content.js  المحتوى (هذا هو الملف الذي يتغير)
assets/js/app.js      البرمجة: اللغة، البوت، النماذج
assets/img/           الشعار والصور
assets/fonts/         الخطوط (Readex Pro و Fraunces — رخصة SIL OFL)
```
